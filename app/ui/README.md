# app/ui

## 目录作用

负责 CLI 界面、富文本展示和用户审批交互。

## 当前文件说明

- `console.py`
  - Rich 全屏终端界面
  - Claude Code 风格欢迎首页
  - 简洁运行态主卡片
  - 底部命令提示栏
  - 总计划/子计划摘要展示
  - 审批与反馈采集
  - 运行时控制命令监听

## 当前设计重点

1. 启动后先展示简洁首页，而不是信息密集的大盘
2. 首页视觉风格向 Claude Code 靠拢，但保留 SqlMate 品牌和猫头像
3. 运行态继续保持简洁，只展示当前节点、摘要和最近活动
4. 用户在关键计划节点参与决策
5. 运行中支持 `/pause`、`/resume`、`/abort`
